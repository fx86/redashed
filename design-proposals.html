Input container — the query box has its own rounded card with an indigo tint border, making it the visual focus of the page rather than another form field.
Actions toolbar inside the box — mic, hint text, and Run button are all inside the input container. This is the "chat input" pattern users know from AI products.
"Add to dashboard" as a filled button — currently both Save and Add to Dashboard are identical ghost buttons. The dashboard action is the key outcome and should look primary.

Summary

Change priority

P0

Unauthenticated pages redirect to /

Blocked users hitting /queries or /dashboard via a shared URL currently see a black screen with a single underlined link. 1-line fix per page.

P1

Nav IA — remove "Query editor" link, move Connections to settings gear

Reduces nav from 4 items + CTA to 2 items + CTA. Eliminates duplicate destination. Small change, big clarity gain.

P2

Dashboard tile header — split title and chart controls onto separate rows, add drag handle

Prevents long questions crowding the controls. Makes draggability discoverable.

P2

Query input as a card — give the main action visual weight

The product's core action currently looks like a small form field. A contained card with toolbar treatment makes it feel like the entry point it is.

P3

Login page — card + grid background, dark-system Google button

More polish than function, but first impressions matter.

P3

Type scale — page headings at text-base/font-semibold, not text-sm/gray-400

One mechanical find-and-replace across pages. Instant legibility improvement.
